# 📊 Retail Sales Dashboard | Excel Analytics Project

## 📌 Project Overview
This project analyzes retail sales performance using Microsoft Excel. The dashboard provides insights into revenue trends, store performance, and holiday impact.

---

## 📈 Key Highlights
- 💰 Total Sales: ₹497.8 Cr
- 📊 Avg Weekly Sales: ₹1.7 Cr
- 🏬 3 Stores Analyzed
- 🎯 30% Higher Sales During Holidays

---

## 📊 Features
- KPI Summary Cards
- Store-wise Performance Comparison
- Weekly Sales Trend
- Holiday Impact Analysis
- Pivot Tables & Slicers

---

## 💡 Business Insights
- Holiday periods significantly boost revenue.
- A small number of stores drive majority of sales.
- Sales follow seasonal demand patterns.

---

## 🛠 Tools Used
- Microsoft Excel
- Pivot Tables
- Charts & Visualization
- Data Cleaning
